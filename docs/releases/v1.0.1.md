# TintLink v1.0.1

TintLink changes accent colors across macOS, VS Code, Codex, and selected Chrome profiles from the menu bar.

**[Download TintLink-1.0.1-macos-arm64.zip](https://github.com/youngchan2/tintlink/releases/download/v1.0.1/TintLink-1.0.1-macos-arm64.zip)**

## Changes

- Launch Chrome through macOS Launch Services to avoid attributing Chrome's app-management requests to TintLink.
- Place Quit beside the status message.
- Remove the system color import button.

## Install

Requires **Apple Silicon and macOS 13+**. No Python or Homebrew needed.

Download the **app ZIP** above, unzip it, and move **TintLink.app** to **Applications**. GitHub's Source code archives are for developers; `.sha256` files from earlier releases are optional checksums, not apps.

This build is **not Apple-notarized**, so macOS may block the first launch. If you trust this download, click **Done**, then open **System Settings → Privacy & Security → Open Anyway** and confirm. [Apple's instructions](https://support.apple.com/102445).

Chrome requires Accessibility permission; updates may require reconnecting it. Chrome keeps its existing theme sync settings and uses the closest supported hue. A color change may occasionally need another attempt after Chrome starts.
