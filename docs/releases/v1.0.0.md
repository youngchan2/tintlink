# TinkLink v1.0.0

TinkLink의 첫 GitHub 배포입니다. 기존 ‘색상 전환기’의 이름을 TinkLink로 변경했습니다.

## 포함 기능

- macOS, VS Code, Codex, Chrome의 강조색을 일곱 프리셋으로 변경
- Chrome의 사용자 지정 프로필 이름 표시, 복수 선택, 모두 선택
- Chrome 자체 테마 변경을 통한 계정 동기화 유지
- 설치된 앱의 실제 아이콘 표시
- Swift 네이티브 앱: Python·Homebrew 등 추가 설치 불필요

## 다운로드 및 설치

1. 아래 Assets에서 **TinkLink-1.0.0-macos-arm64.zip**을 받으세요. Source code는 개발용입니다.
2. 압축을 풀고 **TinkLink.app**을 응용 프로그램 폴더로 옮겨 실행하세요.
3. 메뉴 막대의 팔레트 아이콘을 누릅니다.
4. Chrome을 사용하려면 앱의 **Chrome 연결 허용**에서 손쉬운 사용 권한을 허용하세요.

**지원 환경:** Apple Silicon Mac, macOS 13 이상. Intel Mac은 이번 빌드에 포함하지 않았습니다.

이 배포본은 ad-hoc 서명이며 Apple Developer ID 서명·공증 전입니다. macOS에서 실행 경고가 표시되거나 업데이트 후 손쉬운 사용 권한 재연결이 필요할 수 있습니다.

VS Code는 Dark Modern 테마와 기존 `workbench.colorCustomizations` 항목이 필요합니다. Codex는 라이트·다크 강조색을 먼저 설정해야 합니다. Chrome은 각 프로필의 새 탭 화면을 통해 가까운 색조를 적용하므로 정확한 HEX 값은 달라질 수 있습니다. Chrome 계정의 테마 동기화 설정은 그대로 유지합니다.

자세한 준비 방법과 제한은 [README](https://github.com/youngchan2/tintlink#readme)를 참고하세요. ZIP 검증용 SHA-256 파일을 함께 제공합니다.
