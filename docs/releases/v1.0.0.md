# TintLink v1.0.0

TintLink is a native macOS menu bar app that changes accent colors across macOS, VS Code, Codex, and Chrome.

## Features

- Seven color presets and per-app selection.
- Match apps to the current macOS accent color.
- VS Code Dark Modern accents and text selection colors.
- Codex light and dark theme accents.
- Chrome profile selection, including multiple profiles and select all.
- Chrome theme changes with existing account sync settings preserved.

Download **TintLink-1.0.0-macos-arm64.zip**, move **TintLink.app** to Applications, and open it.

Requires **Apple Silicon and macOS 13+**. No Python or Homebrew needed. Chrome requires Accessibility permission and uses the closest supported hue.

This build is ad-hoc signed and not Apple-notarized. See the [README](https://github.com/youngchan2/tintlink#readme) for setup details.
