# TintLink v1.1.0

Choose which supported apps appear in TintLink, and receive future updates inside the app.

- Edit your list in place to add or remove macOS, VS Code, Codex, and Chrome with sliding controls. Existing selections are preserved; new installs start with an empty list.
- Temporarily pause a listed target with its switch. Removing Chrome preserves your profile selection for when you add it again.
- Check for updates from the top-right menu. Sparkle downloads and verifies updates, then installs and relaunches when you choose to proceed.

Requires Apple Silicon and macOS 13+. Download the app ZIP, unzip it, and move TintLink.app to Applications. Users on 1.0.x must install this version manually once to enable future in-app updates.

This build is not Apple-notarized. Follow the README's first-launch instructions if macOS blocks it. Updates may require reconnecting Accessibility permission for Chrome.
